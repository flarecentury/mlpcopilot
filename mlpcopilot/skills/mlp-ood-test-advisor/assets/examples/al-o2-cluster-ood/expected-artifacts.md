# Expected Artifacts

Suggested artifact set for this OOD case:

- `cluster_case_manifest.yaml`
  - optional project-level manifest recording checkpoint path or hash, reference source, cluster sizes, adsorbate counts, temperature windows, and script versions
- `task_manifest.json`
  - generated by the example setup script and records task directories plus template provenance
- `metrics/force_metrics.json`
  - overall and per-system force error summaries
- `metrics/energy_fluctuation_metrics.json`
  - overall and per-system relative energy fluctuation summaries
- `plots/force_parity.png`
  - DFT vs MLP force parity plot
- `plots/energy_delta.png`
  - centered energy fluctuation parity plot
- `reports/ood_summary.md`
  - final written summary with missing evidence and remaining risk

Current example-script outputs are:

- `task_manifest.json`
- `metrics/force_metrics.json`
- `metrics/energy_fluctuation_metrics.json`
- `metrics/metrics_summary.txt`

- `reports/ood_summary.md`

Optional future additions:

- grouped plots across cluster families
- project-level manifest normalized into a broader artifact-index workflow

Recommended naming fields:

- checkpoint short id
- case name
- temperature window
- cluster family
- creation timestamp if generated outside artifact-indexed workflow

Approval gates to record:

- approval to run expensive CP2K AIMD
- approval to add new DFT labels
- approval to promote or reject the checkpoint for finite-cluster use
