# Decision Question

Can a checkpoint trained mainly on periodic bulk and surface Al/O data be used
for finite `Al_n + mO2` cluster AIMD analysis at `700 K` and `1200 K` without
first adding new cluster-focused reference data?

This question should be answered at the level of explicit evidence, not gut
feeling. The result should distinguish:

- what is already supported by benchmark artifacts;
- what remains untested or weakly tested;
- which additional cluster slices need DFT reference calculations before
  checkpoint promotion.
